Login protection

Against credential stuffing. Every client must solve the bot challenge before reaching these paths, even with bot protection disabled for this service, and each client may submit to them 5 times at once, then once every 12 seconds. Loading the page doesn't count. The challenge needs bot protection turned on in Settings; the limit always applies.

Leaked password check

Checks passwords sent to the login paths above against known data breaches (Have I Been Pwned). Only the first 5 characters of the password's SHA-1 hash leave this server. If the lookup fails or takes over 300 ms, the login goes through unchecked. A hit is logged as leaked_password, counts toward autoban, and reaches the backend with X-Palisade-Leaked-Password: 1 so the app can ask for a password reset.

Visitors get a 503 maintenance page with Retry-After instead of a raw backend error. Trusted IPs and anyone who opened the bypass link still reach the backend, so the team can test the deploy.

Bypass link (sets a cookie for 12 hours)

Lets a fixed number of visitors in at a time; the rest wait in line, first come first served, on a page that refreshes itself. Each place is tied to the visitor's browser and network, so it can't be shared. The queue lives in this Palisade's memory: a restart sends waiting visitors to the back.

Use this for S3-compatible services that accept JavaScript files with PutObject. JavaScript bodies will stream to the backend instead of hitting the WAF's 128 KiB inspected-body limit.

JavaScript request bodies will not be deeply inspected, and the default CRS method/content-type rules are relaxed so S3 PUT works. Other header checks, IP rules, rate limits, and bot protection remain active. Only enable this for a trusted upload endpoint.

Validate this service's JSON request bodies against a JSON Schema before they reach the backend — catches malformed or unexpected fields that generic WAF rules have no way to know are wrong for this specific endpoint. Complements the WAF, it doesn't replace it.

OpenAPI spec

Only the routes and methods your OpenAPI 3.x document declares get through. Required parameters, parameter types and JSON bodies are checked against it too. Paths are matched after the service prefix is stripped, and a servers base path such as /v1 may be present or not. For routes it declares, the spec replaces the JSON Schema above. A violation is logged as openapi_violation.

Inspect responses

Checks the backend's replies for leaked SQL errors, stack traces, PHP/Java/IIS error pages and web shells with the OWASP CRS outbound rules. Logged as response_leak. Only HTML, plain text, JSON and XML up to 64 KiB are inspected; binary, streaming and larger responses pass through untouched. Each inspected response adds about 0.5 ms per KiB.

Route this service's clean, WAF-inspected traffic through the local Varnish cache to serve static assets from memory. Requires the Varnish integration to be enabled on the Settings page.

Also cache logged-in traffic, partitioned per session: each session gets its own cached copy instead of Varnish refusing to cache any request that carries a cookie. Off by default; short TTL (10s) once enabled.

Override Varnish's defaults for this service. Leave blank to use the built-in behavior (1h floor for static assets, no ceiling, 30s grace/keep).

One cache /path or bypass /path per line; the path is a prefix and the longest match wins. cache stores matching responses like static assets, shared by every visitor: cookies and Set-Cookie are dropped, so never use it for per-user pages. bypass sends requests straight to the backend. Unmatched paths keep the default behavior.

Immediately evict what Varnish has cached for this service — everything, or only URLs under a path prefix. Useful right after deploying new content to its backend.

Compresses text responses (HTML, CSS, JavaScript, JSON, SVG) over 1 KB with zstd or gzip, whichever the browser supports, when the backend didn't already compress them. Doesn't need Varnish. Images, video, live event streams and WebSockets pass through unchanged.
